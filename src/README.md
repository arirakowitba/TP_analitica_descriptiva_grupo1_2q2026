# Codigo reutilizable

Esta carpeta debe contener funciones o modulos auxiliares usados por los notebooks.

Ejemplos esperados:

- normalizacion de nombres de columnas y categorias;
- validaciones de calidad;
- carga centralizada de rutas;
- funciones de graficos reutilizables;
- calculo de KPIs o variables derivadas.

La logica extensa o repetida debe moverse aca para que los notebooks queden legibles y reproducibles.
